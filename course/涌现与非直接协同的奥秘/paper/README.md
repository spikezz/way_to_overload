## 摘要

Stigmergy（共识主动性）是一类中介动物间相互作用的机制。1959 年由 Pierre-Paul Grassé
提出，用以解释此前被视为悖论的观察：社会性昆虫中的个体看似独立工作，其群体活动却表现出
协调性。该文回顾了 stigmergy 在社会性昆虫语境下的历史，并讨论了两类不同的 stigmergic
机制——定量 stigmergy（quantitative）与定性 stigmergy（qualitative）的一般性质。
